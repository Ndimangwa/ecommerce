# Django E-commerce — PayPal IPN Integration

## Overview

This project is a Django-based e-commerce application developed to demonstrate the integration of PayPal Instant Payment Notification (IPN) into an online shopping workflow.

The application includes product management, shopping cart functionality, and PayPal payment integration.

## Project Objectives

- Build an e-commerce application using Python and Django.
- Create and manage products.
- Implement shopping cart functionality.
- Integrate PayPal into the checkout process.
- Demonstrate how PayPal IPN communicates payment-related events to a Django application.

## Technologies

- Python
- Django
- PayPal Instant Payment Notification (IPN)

## About PayPal IPN

PayPal IPN is an asynchronous notification mechanism that allows PayPal to send payment event information to an application's server.

A secure implementation should validate incoming notifications, verify payment status and transaction details, and prevent duplicate order processing.
